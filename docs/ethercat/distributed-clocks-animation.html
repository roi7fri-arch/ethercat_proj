The math behind the sync

Four small calculations turn three independent crystals into one shared clock. The numbers below match the three slaves in the animation.

1 · Propagation delaywhy cable length adds no jitter

A broadcast frame latches a receive time-stamp at every port — once on the way out and once on the way back. Both stamps of a pair use the same local clock, so that clock's unknown offset cancels and only the real travel time survives:

RTx = tx1 − tx0  (offset-immune round-trip)

The one-way delay is half of the round-trip still ahead of the slave. ETG's exact form for the last node and a middle node:

tCD = tC1 − tC02     tBC = (tB1 − tB0) − (tC1 − tC0) + tDiff2

For our line the delay from the reference to slave n reduces to:

Dn = RTref − RTn2
RTref = 1700 ns  RT2 = 900 ns  RT3 = 0 ns
D2 = (1700 − 900) / 2 = 400 ns
D3 = (1700 − 0) / 2 = 850 ns

A longer cable changes RT by a fixed, measured amount — a latency, not a random jitter. That is why a 100 m line syncs as tightly as a 1 m line.

2 · Offset compensationregister 0x0920

Each slave's System Time is its local counter plus a constant offset. The master writes the offset so every slave matches the reference:

SystemTimen = LocalTimen + Offsetn ,   Offsetn = Tref − Tlocal,n
Tref = 100000 ns,  slave 2 local = 107450 ns
Offset2 = 100000 − 107450 = −7450 ns

Written to 0x0920. After this every clock reads the same absolute time — the hands jump together in step 2.

3 · Delay compensationregister 0x0928

SYNC0 output pulses are generated from each slave's own System Time. Loading each slave's measured delay Dn into 0x0928 aligns every System Time to the same real instant, so a pulse programmed for one System-Time value fires together on every axis:

SYNC0n fires when SystemTimen = StartTime  ⇒  all axes fire together
D3 = 850 ns is baked into slave 3's clock, so its SYNC0 lines up with slave 1 to within nanoseconds.

4 · Drift compensationcyclic ARMW / FRMW datagram

Two crystals never tick at exactly the same rate. If a slave runs at rate (1 + ε), the error grows over one cycle T:

ΔT = ε · T

Every cycle one datagram carries the reference time to all slaves; each slave's DC control loop nudges its own rate to drive the error back toward zero:

ratenew = rateold · (1 − k · ΔT)
ε = 20 ppm,  T = 1 ms
ΔT = 20×10⁻⁶ × 1×10⁶ ns = 20 ns per cycle → corrected every cycle, so it never accumulates.

This is step 3 in the animation: the hands drift a little, then each message pulls them back — forever.
